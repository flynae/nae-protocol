# The Nae Protocol

Personal portfolio site: cybersecurity, GRC, and digital forensics projects, plus a blog.

Single-file static site (`index.html`). No build step.

## Publish with GitHub Pages
1. Create a new repository (for example `nae-protocol`).
2. Upload `index.html` and `README.md`.
3. Go to Settings > Pages, set the source to the `main` branch and `/ (root)`, then save.
4. Your site will appear at `https://YOUR-USERNAME.github.io/nae-protocol/`.
